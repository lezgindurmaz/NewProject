# Lixoo File Explorer

Lixoo File Explorer, Android için geliştirilmiş, güçlü özelliklere sahip bir dosya yöneticisidir.

## Özellikler
- **Kapsamlı Arşiv Desteği:** Zip, Tar, 7z, Gzip, Bzip2, XZ, LZ4 ve **RAR (v4)** desteği.
- **Disk Kalıbı Yönetimi:** ISO, IMG ve QCOW2 dosyalarını görüntüleme ve oluşturma.
- **Gelişmiş Disk Desteği:** MBR bölümleme tablosuna sahip IMG ve QCOW2 dosyalarını okuyabilme.
- **İçerik Tabanlı Tespit:** Dosya uzantısına bakmaksızın, dosya içeriğinden (magic numbers) dosya türünü belirleme.
- **Root Erişimi:** 'su' komutu ile sistem dosyalarına erişim.
- **Medya Oynatıcı ve Editör:** Dahili metin editörü, müzik çalar ve HTML görüntüleyici.
- **Performans:** Büyük arşivler için optimize edilmiş klasör gezintisi ve duyarlı arama motoru.

## Sürüm Notları (v23.0)

- Dosya uzantısına dayalı tanıma sistemine geri dönüldü (stabilite için).
